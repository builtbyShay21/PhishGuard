# PhishGuard Data Directory

This directory stores datasets for training the PhishGuard machine learning classifier.

## Directory Structure
- `raw/`: Place your raw unformatted dataset CSV files here. These files should contain `url` and `label` columns (0 = benign, 1 = phishing). **DO NOT commit files in this directory to version control.**
- `processed/`: Contains the fully formatted, numerical feature matrices generated by `scripts/prepare_dataset.py`. Ready for model training.

## Usage
To prepare a dataset, place your sources in `data/raw/` and run the preparation script:
```bash
python scripts/prepare_dataset.py -i data/raw/benign.csv data/raw/phishing.csv -o data/processed/phishguard_features.csv
```
